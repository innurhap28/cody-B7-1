# 프로젝트 기획 — 인스타 릴스 제작 코치

## 문제와 대상

팀은 반복적이고 설명을 나열하는 AI 영상보다 제작자의 판단과 영상 구조·연출이 반영된 대본이 필요하다는 문제에서 출발했다. 서비스는 처음 릴스를 기획하는 개인 크리에이터·소규모 제작자가 소재를 촬영 가능한 장면으로 구체화하도록 돕는다. 최신 플랫폼 검열 정책을 확인했다거나 검열 회피·조회수·완주율을 보장한다고 홍보하지 않는다.

## 핵심 사용자 흐름

1. 회원가입·로그인 후 새 릴스 기획을 만든다.
2. AI가 이미 말한 내용은 보존하고 주제·목적·타겟의 관심사/상황·연령·길이·등장 방식·인물·연출·핵심 메시지 중 부족한 조건을 한 번에 최대 두 개 묻는다.
3. 정리한 제작 조건을 보여준다. 사용자가 확인하기 전에는 대본을 생성하지 않는다.
4. 조건에 맞는 제작 템플릿 후보와 관련 원문 개념 카드를 제공해 장면별 시간·화면·대사·자막·연출과 선택 이유를 작성한다.
5. 사용자는 출처·적용 한계를 확인하고 같은 대화방에서 표현과 연출을 수정한다. 이전 대화와 대본 버전은 본인 계정에 저장된다.

## 팀 자료와 연구 방향

사용자가 제공한 이미지 3장은 중복을 제외하면 8개 연구 방향이다. 3막·프라이타크·내러티브, 정보 격차·서스펜스·인지부하, 몽타주·영상 문법·연속 편집, 시각적 스토리텔링, 구조화 프롬프트, 전문가 지식의 규칙화, 시청각 정합성과 저품질감, 창의성·완성도 비교를 다룬다.

이는 팀의 연구 질문이며 이미 효과가 검증됐다는 뜻이 아니다. [연구 방향](RESEARCH_AGENDA.md)과 [실제 연결 자료](KNOWLEDGE.md)를 구분한다. 현재는 공개 원문의 검토한 절을 요약한 21개 카드를 키워드로 검색해 참조한다. PDF 전체 학습·파인튜닝을 완료한 것이 아니며, 향후 확보할 PDF·강의자료는 이용 조건·원문·페이지·팀 검토를 확인한 뒤 연결한다.

## 제품 범위와 평가

현재 제품은 기획·대본·연출안·근거를 제공한다. 영상 렌더링·인스타그램 업로드·자동 대량 수집은 구현 범위가 아니다. 같은 소재·타겟·길이로 일반 대본과 이론 참고 대본을 비교하고, 서사 일관성·연출 구체성·촬영 가능성·시청각 정합성을 팀이 평가해야 한다.

기술 과제의 필수 범위는 FastAPI, 로그인 제한, 서버 AI 호출, 문맥 유지, SQLite 사용자별 로그, 입력/오류/운영 로그, Git 협업, 기술 문서, 평가 시 외부 접속 URL이다. 외부 배포와 팀원별 실제 기여는 완료 증거가 필요하다.
