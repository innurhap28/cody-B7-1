# 화면 사용 방법

1. /signup에서 가입하고 /login에서 로그인한다. 동일한 이메일은 하나의 계정으로 관리한다.
2. 왼쪽의 ‘새 릴스 기획’을 누르고 아이디어를 자유롭게 입력한다. 예: ‘20대 대학생에게 책상 정리 방법을 보여주는 30초 인스타 릴스를 만들고 싶어요.’
3. 추가 질문에 답한다. 등장인물이 없거나 얼굴을 촬영하지 않는 경우도 그대로 말한다. 이미 전달한 조건은 다시 입력하지 않아도 된다.
4. 오른쪽 제작 조건을 확인하고 ‘이 조건으로 대본 작성’을 누른다. AI 응답에는 수십 초가 걸릴 수 있으며 중복 전송을 막는다.
5. 장면별 시간·화면·대사·자막·연출, 구조 선택 이유와 출처를 확인한다.
6. 표현을 바꾸려면 수정 내용을 입력하고 ‘입력한 내용으로 대본 수정’을 누른다. 타겟·길이 등 기획 자체를 바꾸려면 일반 메시지로 조건을 갱신한 뒤 다시 확인한다.
7. 왼쪽 목록으로 기존 대화를 선택한다. 오류 시 안내를 확인하고 새로 불러오기로 저장 상태를 확인한다. 본인의 계정 기록만 조회할 수 있다.

자료의 학술 설명과 팀의 제작 제안을 구분해 확인한다. 자료가 없는 설명은 확인 불가로 안내할 수 있다. 생성된 문장과 촬영 가능성은 제작자가 최종 검토한다.
